## 💴 Featured Project — Mementos

> A full-stack personal finance tracker with a **Persona 5-inspired UI**

**PERN Stack** — PostgreSQL · Express · React · Node.js

**Highlights:**
- JWT authentication with token denylist (`jti`), HttpOnly cookies, and a scheduled cleanup job
- Google OAuth 2.0 login via Passport.js
- Full CRUD for accounts, transactions, and custom categories
- Animated route transitions and a P5-style panel wipe effect
- Security hardening: rate limiting, Helmet headers, SSRF protection, and fail-closed auth middleware
- Deployed on Render with separate frontend (Static Site) and backend (Web Service) repos
